# AI Chat Assistant — Setup & Build Log

A chronological record of everything done to take the AI chat assistant from zero to a working, deployed backend. For the original architecture/design rationale, see [`ai-chat-assistant-plan.md`](./ai-chat-assistant-plan.md) — this doc covers what was actually *built and configured*, in the order it happened, including the problems hit along the way.

## Current status

- **Frontend widget**: done, working.
- **Backend (`/api/chat`)**: done, deployed on Vercel, responding correctly.
- **Hosting**: split — Angular UI is meant for **Hostinger**, `/api/chat` is on **Vercel**. The Hostinger upload has **not** happened yet (still pending as of this doc).
- **`environment.ts` (dev config)**: currently has its `apiBaseUrl` temporarily pointed at the live Vercel URL for local testing via `ng serve`. This is intentionally left uncommitted — see "Local testing method" below.

## 1. Frontend: the chat widget

New standalone Angular component, added as global chrome (rendered once for every route, same pattern as the navbar/footer):

- `src/app/core/layout/ai-chat/ai-chat.component.ts` / `.html` / `.scss`
- `src/app/core/layout/ai-chat/ai-chat.service.ts` — thin `HttpClient` wrapper around `POST /api/chat`
- Wired into `app.component.html`/`app.component.ts` as `<app-ai-chat />`
- `provideHttpClient(withFetch())` added to `app.config.ts` (the project had no `HttpClient` provider before this)

Design: floating gradient button (bottom-right, positioned to stack above the existing back-to-top/theme-toggle buttons on the home page), glassmorphic panel, starter prompts, a real profile photo as the avatar (cropped from `ai-assisted-picture.jpeg`, which originally had large black letterbox bars — auto-detected and removed), loading/error states, and a disclaimer linking to `/book-call` and `/send-message`.

## 2. Backend: the Vercel function

- `api/chat.ts` — validates the request, rate-limits per IP (in-memory, 8 requests/60s), enforces CORS via an `ALLOWED_ORIGIN` env var, builds a scoped system prompt + injects portfolio content as grounding context, calls Gemini, retries once on a transient 503, and never leaks internals (API key, stack traces) to the client on failure.
- `api/tsconfig.json` — a **scoped** TypeScript config just for this function (see Problem #1 below for why it's needed).
- `vercel.json` — configures the Vercel project to skip the Angular build entirely (`buildCommand` is a no-op `echo`, `outputDirectory` points at a placeholder `api-static/` folder) since Vercel here only ever serves the API, not the site itself.

## 3. Choosing a model provider: Google Gemini (free tier)

Originally planned around Anthropic's Claude API, but switched to Google Gemini specifically to keep the feature at **$0 cost** — Gemini's free tier (via [aistudio.google.com](https://aistudio.google.com)) requires no card on file, unlike Anthropic/OpenAI. Key generated from AI Studio → API Keys → Create API key.

## 5. Problems hit, in order, and how they were fixed

1. **Function crashed on every request (`Cannot use import statement outside a module`).** Vercel compiled `api/chat.ts` using the repo's root `tsconfig.json`, which sets `"module": "ES2022"` for Angular's build — producing ESM `import` syntax that Node's default CommonJS loader couldn't parse. Fixed by adding `api/tsconfig.json`, scoped to just the function, forcing `"module": "commonjs"` (with `"moduleResolution": "node10"` and `"rootDir": ".."` to satisfy the compiler) — without touching Angular's own build config.
2. **`gemini-2.0-flash-lite` no longer existed** (model naming had moved on since original planning) — switched to `gemini-3.5-flash`, confirmed via Google AI Studio's own "Get code" feature rather than guessing.
3. **`gemini-3.5-flash` returned `503 UNAVAILABLE`** ("high demand"). Not a bug — Google's flagship free-tier model was simply overloaded. Switched to `gemini-3.1-flash-lite`, a lighter, high-volume-optimized model less likely to hit that ceiling. Also added a single automatic retry (800ms delay) specifically for 503s, since Google's own error message says these are usually transient.
4. **A Gemini API key was accidentally pasted into chat.** Treated as compromised on principle (any secret that leaves its intended storage should be rotated, even if the actual risk was low here — free tier, no billing attached) — deleted and regenerated in AI Studio.
5. **Reply quality issues found during real testing**, fixed via system prompt iterations in `api/chat.ts`:
   - Replies used the full formal name ("Engr. Jatsen P. Gesta") → instructed to say "Jat" instead.
   - Replies contained raw markdown (`**bold**`, `*` bullets) that rendered as literal asterisks in the plain-text chat bubble → instructed to reply in plain conversational text only.
   - Replies repeated the same boilerplate experience summary regardless of the question, and bled unrelated details (like a company name) from earlier turns into later replies → instructed to answer only what's specifically asked, and keep off-topic declines to one self-contained sentence.
   - First-reply greetings used a stiff "I am the portfolio assistant for..." template → instructed to open more like a friendly guide instead.

## 6. Local testing method

Since the UI (Hostinger) and API (Vercel) are on different origins, testing the deployed function from a local `ng serve` requires temporarily pointing the dev environment at it:

```ts
// src/environments/environment.ts
apiBaseUrl: 'https://work-portfolio-nu-five.vercel.app',
```

This is deliberately **left uncommitted** — `environment.ts`'s committed default is an empty string (relative `/api/chat`, only meaningful if something like `vercel dev` serves both parts on the same origin). Revert this line to `''` before committing anything else in this file.

## Maintenance notes

- **If Gemini starts erroring again** (404 model-not-found, or another 503 spree): get the current correct model ID directly from Google — open [aistudio.google.com](https://aistudio.google.com), pick a model, and use its "Get code" feature to see the exact model string, rather than guessing. Update `GEMINI_MODEL` in `api/chat.ts`.
- **System prompt** lives entirely in `buildSystemPrompt()` in `api/chat.ts` — all tone, formatting, and scoping rules are adjusted there.
- **Rate limit / retry tuning**: `RATE_LIMIT_MAX_REQUESTS`, `RATE_LIMIT_WINDOW_MS`, `MAX_ATTEMPTS`, `RETRY_DELAY_MS` are all top-of-file constants in `api/chat.ts`.
- **Rotating the Gemini key**: delete + recreate in AI Studio, then update the `GEMINI_API_KEY` value in Vercel's Environment Variables and redeploy.
